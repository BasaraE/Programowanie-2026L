# MovieTracker

Projekt wykonany w ramach poprawy efektu P_U01.

## Autor
Bohdan Krakoviatskyi  
Nr albumu: 73076

## Opis projektu
MovieTracker to prosta aplikacja internetowa do zapisywania tytułów filmów.

## Zastosowane technologie
- HTML
- CSS
- JavaScript
- localStorage

## Funkcjonalności
- dodawanie filmów do listy,
- sekcja „Filmy dokumentalne”,
- favicon strony,
- zapis listy filmów do localStorage,
- przycisk czyszczenia listy filmów,
- komunikat po wyczyszczeniu listy.

## Informacja
Projekt został przygotowany w repozytorium GitHub zgodnie z wymaganiami zadania P_U01.
